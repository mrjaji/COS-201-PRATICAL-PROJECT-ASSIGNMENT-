Assignment Title

Variables, Data Types, Expressions and Input/Output.

Objective

To understand Java variables, data types, arithmetic expressions, operators, and input/output operations.

Tools Used

* Java Development Kit (JDK)
* Visual Studio Code (VS Code)

Practical Exercises

1. SimpleCalculator.java
A programme that accepts two numbers and performs addition, subtraction, multiplication and division.

2. AverageCalculator.java
A programme that accepts a student’s name and three scores, calculates the total and average, and displays the results.

3. ItemCost.java
A programme that accepts an item name, quantity and unit price, then calculates and displays the total cost.

Concepts Learned

* Variables and constants
* Java data types
* Arithmetic operators
* Assignment operators
* Relational and logical operators
* Type conversion
* User input using Scanner
* Output using System.out.println()

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Navigate to the week03 folder.
4. Compile each Java file using javac.
5. Run each programme using java.

Learning Outcome

I learned how to declare and use variables, work with different data types, perform mathematical calculations, accept user input and display results using Java.
